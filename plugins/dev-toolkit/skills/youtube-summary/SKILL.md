# YouTube動画リンクの出力構成

以下の3部構成で必ず出力する。

## 1. 図解化

ASCIIダイアグラムをコードブロックで描画する。
- 60文字の水平線で開始・終了
- 1行60文字以内
- フローチャート形式を優先

## 2. タイムライン

リスト形式で、タイムスタンプ付きURLを含めること。

```
1. [開始時間〜終了時間] タイトル
   - 要約：20〜30文字以内で内容を簡潔に記述
   - URL：タイムスタンプ付きのYouTube URL
```

- 要約は必ず20〜30文字以内に収めること
- 体言止めや短縮表現を積極的に使うこと

## 3. 結論ベースの要約

- **結論（1文）**：動画が最終的に主張していること
- **論理の流れ（因果チェーン）**：A → B → C 形式
- **主張の構造（ロジックツリー）**：階層的に列挙
- **キー指標（KPIサマリー）**：数値・統計・事実を箇条書き
- **不確実性・前提条件**：結論が成立するための前提を明記
